# Code of conduct

iOS Local LLM is intended to be a welcoming, practical, and technically rigorous
project.

## Expected behavior

- Be respectful and specific.
- Critique ideas and code, not people.
- Assume good intent while still asking for evidence.
- Respect privacy, copyright, licenses, and security boundaries.
- Accept maintainer decisions about scope and release risk.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, deliberate
misinformation, doxxing, spam, and publishing another person's private
information are not tolerated.

## Enforcement

Report conduct concerns privately to `mesutcy@gmail.com`. Include relevant
links or screenshots. Reports will be reviewed in confidence where practical.
Maintainers may edit or remove content, reject contributions, issue warnings,
or temporarily or permanently restrict participation.

This policy applies in project spaces and when someone publicly represents the
project.
