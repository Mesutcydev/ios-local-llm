# Support

iOS Local LLM is community-maintained and provided without warranty.

- Use GitHub Issues for reproducible bugs.
- Use GitHub Discussions for setup questions and ideas when available.
- Read [SETUP_INSTRUCTIONS.md](SETUP_INSTRUCTIONS.md) before reporting build
  problems.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

When filing a bug, include your macOS, Xcode, iOS, and device versions; the
model and quantization involved; the smallest reproduction; and relevant logs
with tokens, file paths, and personal data removed.
