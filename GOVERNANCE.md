# Governance

iOS Local LLM is currently a maintainer-led open-source project.

## Roles

- **Maintainers** merge changes, manage releases, handle security reports, and
  make final technical and community decisions.
- **Contributors** propose changes through issues and pull requests.
- **Reviewers** are contributors trusted for recurring subject-area review;
  this role does not automatically grant merge access.

Current roles are listed in [MAINTAINERS.md](MAINTAINERS.md).

## Decisions

Routine decisions are made in public issues and pull requests. Significant
changes—licensing, supported platforms, security boundaries, data handling,
governance, or removal of a public interface—require a written proposal and a
reasonable community comment period.

The maintainer seeks consensus first. When consensus is not possible, the
maintainer records the decision and rationale publicly. Conflicts of interest
must be disclosed and the affected person should recuse themselves when
another qualified reviewer is available.

## Becoming a maintainer

Sustained, constructive contributions; sound review judgment; respect for the
Code of Conduct; and reliable security practices are prerequisites. A current
maintainer may nominate a contributor in a public issue. Maintainer status can
be removed for inactivity, request, security risk, or Code of Conduct
violations, with the rationale recorded when it is safe to do so.

## Project assets

Repository access follows least privilege and should use two-factor
authentication. No single sponsor or employer owns project decisions merely
by providing funding. Sponsorships and material conflicts will be disclosed.

This governance model should be revisited after the project has multiple
active maintainers.
