# Roadmap

This roadmap communicates direction, not a promise of delivery dates.

## Near term

- Make clean-clone iOS and Catalyst framework builds repeatable.
- Expand unit tests around memory admission, thermal policy, cancellation,
  authentication, and model lifecycle.
- Publish an honest physical-device validation matrix with reproducible steps.
- Improve first-run fork configuration for bundle IDs, App Groups, CloudKit,
  and signing.
- Stabilize the reusable runtime boundaries documented in
  `Docs/REUSABLE_COMPONENTS.md`.

## Next

- Extract low-coupling runtime utilities into independently versioned Swift
  packages.
- Add protocol conformance fixtures for OpenAI-, Anthropic-, and
  Ollama-compatible routes.
- Add accessibility and localization coverage for core flows.
- Keep dependency automation, SBOM generation, and release provenance current.
- Recruit reviewers and a second maintainer through sustained contributions.

## Longer term

- Offer a supported package-level local inference foundation.
- Build a documented compatibility suite for coding-agent integrations.
- Evaluate participation in OpenSSF, fiscal-hosting, mentorship, and other
  open-source programs after their factual prerequisites are met.

Requests and proposals belong in GitHub Issues. See
[GOVERNANCE.md](GOVERNANCE.md) for decision-making.
